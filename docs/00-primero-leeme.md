# Guardián PyME — empezar por acá

Este índice evita improvisar frente al primer cliente.

## Antes de vender

1. Leer la [oferta comercial](01-oferta-comercial.md).
2. No prometer tareas que figuren fuera de alcance.
3. Crear el [Link de Pago y la agenda](10-cobro-y-agenda.md).
4. Hacer un ensayo completo con una computadora propia.

## Cuando aparece un cliente

1. Seguir el [runbook del primer cliente](12-runbook-primer-cliente.md).
2. Obtener la [autorización escrita](13-autorizacion-diagnostico.md).
3. Usar el [checklist de diagnóstico](02-checklist-diagnostico.md).
4. Entregar el [informe](03-informe-cliente.md).
5. Presupuestar correcciones por separado.

## Cómo registrar la información

El sitio comercial no almacena datos personales. Para los primeros clientes se
usa un expediente separado por empresa, fuera del repositorio de código. La
estructura y las relaciones están en el
[modelo de datos](11-modelo-de-datos.md).

## Regla de seguridad

Si no existe autorización escrita, alcance identificable y un responsable del
cliente disponible, no se ejecuta la revisión.
